# MyTools - Multi-Page Edition (Vercel Ready)

## Pages & Structure
- `index.html` - Home Dashboard with links to all tools & full-screen workspace background
- `image-converter.html` - Bulk Image Converter (ZIP export)
- `pdf-to-excel.html` - PDF to Excel (.xlsx) Converter
- `bulk-rename.html` - Bulk Image Rename via CSV
- `url-downloader.html` - Bulk Image URL to ZIP Downloader (up to 1,000 URLs + Basic Auth)
- `file-share.html` - Quick File & ZIP Drop (up to 1GB via Firebase)
- `api/fetch-image.js` - Vercel Serverless proxy for URL image downloading
